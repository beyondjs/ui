# Local UI 0.44.0: the sweep of 2026-10-27

Evidence baseline: UI `7504e7f` (0.42.0) on `feature/next` plus this change, made on 2026-10-27 and 28 for the suite's sweep of the open pendings ("resuelve cualquier pendiente que haya quedado"). Another session is releasing its own 0.43.0 (the inbox's page rows and list rules), so this release is numbered 0.44.0. **0.43.0 was not committed on `feature/next` when these runs were made**, so this branch is not yet rebased onto it, and its archive is a candidate: the release is final once the branch is rebased onto 0.43.0, packed again and its affected checks run again.

## Why

Fifteen of the suite's pendings named the package (`methodology/pendings/ui-*.md`), and the products' own pendings waited on several of them (list rules L3, L6, L8, L10; LOAD-01's held places; the outage rules D132/D163; D187's focus). Six branches did them in parallel and were integrated here, then reviewed independently.

## What changed

- **Words chosen from the language** (`ui-language-selection`). `Labels` takes a component's set (`{ en, es }`) and its `locale`, and chooses: the given `labels` win, then the component's `locale`, then `<html lang>` (which `Preferences` sets from the account, D07, so reading it follows the family rule), then English; a key the chosen language lacks comes from English. Every DOM and React component that draws words builds them so. A product that passes `labels: X.labels.es` keeps working. Dates follow the page's language when it is not the runtime's (`Age`, `TimeWords`). The Spanish retry word is "Reintentar" in every set (`Session` and dictation said "Intentar de nuevo"); the writing guide and the recovery guide name none, so the word the outage line already used was kept, and the owner is asked.
- **A page's places held before its read** (`ui-load01-gaps`, LOAD-01, D185). `PageHeader`'s `waiting` (a pending title named "Loading…", busy and out of focus, a router's focus landing with the title), `reserved()` / `Reserved` for an action known only after the read, a facts line that is a `div` and may hold a control, `Section.part()` / `SectionPart` for one waiting part of a section, a waiting `Sidebar` object group and an `Arrival` with `href: null` held unseen until its way back is known. Item 6 (older hosts) is closed: every host of Projects' repository task vendors 0.41.0 or later. A reserved action on a `detail` page can still move sideways when the real title replaces the placeholder: no placeholder knows the title's width.
- **The wheel over a panel kept in view** (`ui-page-panel-wheel-trap`). Measured first: with `overscroll-behavior: contain`, Chrome 156 kept the page at 0 px under the wheel over a `PagePanel` that fits. `.bui-page-panel` drops it; a panel that scrolls still scrolls itself, and at its end the next wheel scrolls the page.
- **Outages** (`ui-outage-close-followups`, `ui-inbox-loading-grace`). The family bar's notice takes `outage` (`true` or `{ moments, locale, labels }`): the warning tone, its mark and `AgainLine`'s last try. A partial outage in the inbox and its panel is one line per product that did not answer ("Beyond Delegate did not answer", from the catalog of causes, else the display name, else the id) and one sentence after ("Its notifications are not listed." / «Sus notificaciones no aparecen en la lista.»); the `partial` key is replaced by `silent` and `unlisted`. `Recovery`'s narrow and page forms leave no gap for a part they do not draw (offline, or without Technical details), and an offline line with no evidence ends at its inset. The inbox's first read is the shared `waiting` in the list's place, so the opening and the 300 ms grace see it. `DetailsRecord` lists `locale` and `labels`.
- **Lists and tables** (`ui-list-rules-gaps`, `ui-datatable-framed-first-part`, `ui-datatable-narrow-sort`). Gap 1: a period filter (`kind: 'period'`, values `P{n}D`, `YYYY-MM` and a restored `YYYY-MM-DD/YYYY-MM-DD`, UTC days, `Period.range`), a chooser, never typed (D56). Gap 2: React `Collection`'s `empty.action` (and the DOM's `{ label, href, run }`); React keeps no `onRender`, which no React consumer uses. Gap 3: `DataTable`'s `menu(row)`, a row menu column with L6's reveal that stays beside the name on narrow rows. Gap 4: `useCollectionTools` and `<CollectionTools>`. Gap 7: decided in 0.39.0 (tables mark no words and have no row keys). Gap 8: `Differ` and `row(row, { differ })`. Gap 9: not built: the region below a row is `.bui-row-under` (0.30.0), and a `ListRow` `detail` would sit under the row's stretched target. A narrow `DataTable` draws its own sort line ("Sort by" / «Ordenar por») reported through the header's `onchange`, and `framed` lifts a table only while it leads its box, so a product sets it once.
- **Focus** (`ui-focus-development-warning`, `ui-ring-under-tailwind-preflight`, D187). `Focus`, a development check of the shape of `Hierarchy` and `Ellipses`, which a `Page` starts: it warns once when a place reading starts draws an outline or a ring, and when a box that takes typing draws an outline, the ring's coral or an unmarked danger. In Firefox `focus.css` restates the ring at (0,1,1) on `:-moz-focusring`, one type selector above Tailwind 3's unlayered preflight and under every component's own rule, leaving boxes that take typing to their edge; the command palette's field draws none on `:focus-visible`. Accounts, Snapshots and CDN's two applications drop their own `:-moz-focusring` rule.
- **The rest.** A busy `Button` keeps one ellipsis on a label that ends in one (`ui-button-busy-ellipsis`, DOM and React). `ProviderWindow` takes `name` (`ui-provider-window-name`), so Projects names each trip's window after its attempt. A cramped `Lanes` block folds the live line's room last (`now`: the title takes three quarters of what the two share) before it cuts a title (`ui-lanes-cramped-titles`); the acceptance's 42rem block still cuts its one very long title after the three folds and shows it whole on hover and focus. The inset measurer reads what `::before` and `::after` draw (`ui-measurer-generated-words`), through `acceptance/support/generated.mjs`, which products copy with `insets.mjs`.

## The independent review and its corrections

An independent reviewer read the whole diff and found no blocker. Corrected in the release: React's busy `Button` still doubled the ellipsis; a Spanish month's name was not in sentence case; the Firefox ring rule did not leave editable regions and text roles to their edge (now excluded at no added specificity); a framed table after an empty React host or one holding only a hidden part did not lift; dates did not follow a page language other than the runtime's; four new React suites did not run on React 18; two catalog lines still named the removed `partial` key. Kept as recorded limits: the Firefox ring also outranks a product's own one-class rule that takes a control's outline off (none in the suite's products, by source search); React `Collection` reads `empty` at each read of the list, not on a prop change alone.
