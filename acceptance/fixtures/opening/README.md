# Opening fixture

`index.html` and `ready.js` are a fictional application that names the family's `session` step on its waiting element, waits for one read and then draws a useful screen under a bar with the family lockup's parts (`.bui-family .bui-lockup-mark`, `.bui-lockup-name`), where the opening hands its identity over. The opening acceptance holds its module or read, fails them, takes the connection away or lets them finish; it tests the document presentation, never product integration. The wordmark is taken from the existing DOM acceptance fixture. With `?unnamed` its waiting element is a region that names no step and adds a note while it waits. `earlier.html` is the opening's markup before 0.21.0, served with this version's controller and stylesheet as a development server whose package changed under it would.
