# Brand fixtures

A copy of the family's published wordmark, used only by the family bar page of the browser acceptance to measure the lockup against it. It is a test fixture: the package ships no brand asset, and consumers pass their own wordmark (`brand.src`). Rubik is not copied here: every acceptance page imports the package's own `@beyond-js/ui/fonts.css`, as a product does.
